# Simulação de Conta Bancária

## Descrição
Projeto desenvolvido para simular o funcionamento básico de uma conta bancária, permitindo operações como depósito, saque e consulta de saldo.

## Objetivo
Aplicar conceitos de lógica de programação e regras de negócio, simulando operações financeiras comuns em sistemas bancários.

## Contexto de Uso (Simulação)
Em um cenário real, este sistema poderia representar o módulo inicial de uma aplicação bancária ou financeira, responsável por gerenciar operações básicas de contas de clientes.

O projeto simula regras que normalmente existem em sistemas reais, como validação de saldo e controle de operações.

## Funcionalidades
- Criação de conta bancária
- Depósito de valores
- Saque com validação de saldo
- Consulta de saldo atual
- Registro das operações realizadas

## Tecnologias Utilizadas
- Java
- Programação Orientada a Objetos
- Lógica de Programação
- Git / GitHub

## Exemplo de Fluxo
1. Usuário cria uma conta bancária
2. Realiza um depósito inicial
3. Solicita um saque
4. Sistema valida o saldo disponível
5. Saldo é atualizado e exibido ao usuário

## Como Executar
1. Clonar o repositório
2. Abrir o projeto em uma IDE Java
3. Executar a classe principal do projeto
4. Interagir via console conforme instruções exibidas

## Observações
Projeto com foco educacional, voltado para prática de lógica, modelagem de classes e implementação de regras de negócio comuns a sistemas financeiros.
